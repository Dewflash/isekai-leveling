# Sanctuary visual north star

`sanctuary-final-look-reference.png` is a direction reference, not a final map layout.

It establishes the intended production language for Isekai Leveling:

- readable Last Day on Earth-style spatial compression with human-scale props;
- cozy anime-fantasy forms with cartoon/toon shading and lightly pixel-inspired readability;
- warm Hearth lighting, cool woodland edges, colorful materials, and animated-looking atmosphere;
- substantial timber, stone, rope, canvas, crops, livestock, storage, and expedition infrastructure;
- visible construction stages: blueprint, delivered materials, scaffold, then a useful finished building;
- clear paths and sightlines without requiring a fixed arrangement.

The player owns the final sanctuary layout. Structures such as cisterns, future housing,
storage, workshops, pens, gardens, and decorative utility objects must be placeable on
the build grid, subject to footprint collisions, reserved landmarks, and practical access.
The reference composition is only a visual acceptance test: any player-authored layout
should still feel like the same world.
