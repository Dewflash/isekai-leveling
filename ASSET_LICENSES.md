# Prodewty Asset Ledger

This build is self-contained and does not require the owner to download or
replace anything. It combines original procedural low-poly content created in
GDScript with a small, coherent CC0 nature family sourced and imported by the
assistant. Runtime glTF parsing keeps the asset pass usable on a clean Godot
launch without relying on a local editor import cache.

| Asset family | Creator/source | License | Use |
| --- | --- | --- | --- |
| Procedural meshes and materials | Codex-generated for Prodewty | Original project code | World, character, props, UI accents |
| Procedural audio | Codex-generated `AudioStreamGenerator` tones | Original project code | Ambience, rain, station, weather modulation, and fallback feedback |
| Stylized Nature MegaKit Standard | [Quaternius official pack page](https://quaternius.com/packs/stylizednaturemegakit.html), [author-published OpenGameArt mirror](https://opengameart.org/content/stylized-nature-megakit) | CC0 1.0 Universal; included `License_Standard.txt` | Imported glTF trees, rocks, and mushroom used across Sanctuary and expedition maps |
| Farm Animal Pack | [Quaternius official pack page](https://quaternius.com/packs/farmanimal.html), [author-published archive mirror](https://opengameart.org/sites/default/files/Farm%20Animals%20by%20%40Quaternius.zip) | CC0; included `License.txt` | Checked-in source family for the animated resident/wildlife pass; current chicken keeps a procedural fallback until glTF conversion |
| RPG Audio | [Kenney RPG Audio](https://kenney.nl/assets/rpg-audio) | CC0; included `License.txt` | Sampled footsteps, chopping, impacts, discovery, quest, and craft cues |
| Interface Sounds | [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds) | CC0 | Sampled UI click cue |
| Music loops | [Two Simple Game Music Loops](https://opengameart.org/content/two-simple-game-music-loops) | CC0 as published by the author | Looped Sanctuary/expedition score through the Music bus |
| Adventure UI / Mobile Controls | [Kenney UI Pack - Adventure](https://kenney.nl/assets/ui-pack-adventure), [Kenney Mobile Controls](https://kenney.nl/assets/mobile-controls) | CC0 | Checked-in source libraries for the safe-area and touch theme pass |

The downloaded archive was validated before extraction. Its SHA-256 is recorded
in [`ASSET_MANIFEST.md`](ASSET_MANIFEST.md); only the glTF subset and the
included license are needed by the running game.

## Researched optional sources

These official pages were also reviewed as possible future expansions. They
are not runtime dependencies of the current checkout:

| Source | License/status | Review note |
| --- | --- | --- |
| [Quaternius Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) | CC0 per source page | Future animated player/villager pass |
| [Quaternius Ultimate Stylized Nature](https://quaternius.com/packs/ultimatestylizednature.html) | CC0 per source page | Future foliage variety |
| [Quaternius Animated Monster Pack](https://quaternius.com/packs/animatedmonster.html) | CC0 per source page | Future animated guardian pass |
| [Godot 4.7 scene importer](https://docs.godotengine.org/en/4.7/classes/class_resourceimporterscene.html) | Official engine documentation | Import constraints reviewed before any future glTF pass |

The current game remains reproducible from the repository alone: sourced model
files are checked into `assets/quaternius-stylized-nature/glTF`, source animal
and UI packages are checked into `assets/sourced/`, Kenney samples are loaded
by `scripts/audio_director.gd`, and gameplay animation tweens, particles,
feedback, buildings, player, guardian visuals, and fallback audio remain
generated by the project code.
